# Hadoop Crime Analysis Project

## Overview
This project analyzes crime data across multiple years using the Hadoop ecosystem. The goal is to process large datasets efficiently and generate insights such as crime trends, geographic distribution, and temporal patterns.

The project uses **HDFS for distributed storage and PySpark for large-scale data processing**, followed by visualization to identify patterns in crime data.

---

## Problem Statement
Crime datasets often span multiple years and regions, making them difficult to process using traditional tools. This project demonstrates how **big data frameworks can process large crime datasets efficiently** and generate insights for analysis and visualization.

---

## Dataset
The dataset consists of multiple CSV files containing crime statistics across different states and districts.

Typical fields include:

- State  
- District  
- Year  
- Crime Type  
- Number of Cases  

These datasets are stored and processed in **HDFS (Hadoop Distributed File System)**.

- Python
